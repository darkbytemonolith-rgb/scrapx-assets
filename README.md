# scrapx-assets

Images and short videos for [scrapx.dark-byte.org](https://scrapx.dark-byte.org), served through the jsDelivr CDN.

The originals also live in the ScrapX repo under `public-web/art`. Copy changes here, commit, then create a new tag (`v2`, `v3`, ...) and point the site at it:

```text
https://cdn.jsdelivr.net/gh/darkbytemonolith-rgb/scrapx-assets@<tag>/art/cast/wick-hero.webp
```

Never move or delete a tag that the site uses. jsDelivr keeps files from a tag permanently, so the links keep working.
